# Sanitized VRDC Pipeline Memo

**Author:** Jiayu Feng

This repository contains a sanitized technical memo documenting a research data pipeline used in a Virtual Research Data Center (VRDC) environment.

The repository is intentionally limited to material that can be shared publicly. Its purpose is to demonstrate how I document and structure restricted-data research workflows without exposing protected data, credentials, or non-shareable project materials.

## Repository contents

- `Sanitized_Pipeline_Memo.pdf` — sanitized technical documentation of the pipeline.

## Scope

Because the underlying work was conducted in a restricted-data environment, this repository does **not** contain restricted source data, credentials, environment-specific secrets, or other non-shareable materials.

This repository should therefore be read as a portfolio artifact documenting research workflow and pipeline design, rather than as a fully reproducible public release of the underlying restricted-data analysis.
